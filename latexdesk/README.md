# LaTeX Desk: public resources

Images and documents linked from the [LaTeX Desk](https://marketplace.visualstudio.com/items?itemName=esquaredsystems.latexdesk)
README on the Visual Studio Marketplace and in VS Code's extension page. The extension's source
repository is private, so the README's relative links resolve here instead.

The files in this folder are copied from the extension repository when a version is published.
They are covered by the extension's MIT license ([LICENSE](LICENSE)), except `thesis/LICENSE`,
which describes the separately licensed test thesis. Do not edit them here.
